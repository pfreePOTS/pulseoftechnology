# rod

## What it does
Humanizes marketing and product copy in a warm, casual, professional voice. Cuts em-dash overuse, hyperbole, and consultant clichés. Also audits LLM/agent system prompts so they do not instruct models to produce that language.

## When to use it
User asks for the Rod skill, a Rod pass, humanizer, de-AI copy, prompt voice audit, or to make writing (or prompts) sound like a person wrote it.
